 Trabajos de IA – Riwi
Repositorio que recopila las actividades, ejercicios y apuntes desarrollados durante las sesiones de formación en Inteligencia Artificial en Riwi. El material está organizado por sesiones e incluye desde algoritmos secuenciales (como la preparación de un tinto) hasta el diseño conceptual de una plataforma web educativa.

Descripción del Proyecto
Este repositorio funciona como un portafolio de aprendizaje donde se documentan las prácticas realizadas en clase. Los contenidos abarcan:

Algoritmos paso a paso y su representación visual (diagramas de flujo).

Ejercicios introductorios de programación en Python.

Actividades de análisis y toma de decisiones con apoyo de IA (ej. caso de “tres cupos, ocho estudiantes”).

Documentación técnica y conceptual para el diseño de una plataforma web educativa (DevForge).

El objetivo es servir como material de consulta y evidencia del progreso en la formación en IA y fundamentos de programación.

🛠️ Tecnologías Utilizadas
Tecnología	Uso en el proyecto
Markdown (.md)	Documentación de algoritmos, apuntes y actividades.
Python (.py)	Scripts de ejercicios introductorios (ej. ejercicio1.py en la sesión 1).
Imágenes (PNG)	Diagramas de flujo o esquemas (ej. DIAGRAMACAFE.PNG).
Git / GitHub	Control de versiones y alojamiento del repositorio.
Nota: No se utilizan frameworks avanzados de IA ni librerías externas; el enfoque es introductorio y de fundamentos.

🔍 Detalle de los archivos principales
TRABAJOSDEIA/IA-Sesion-1/
Carpeta que agrupa  un script en Python (ejercicio1.py) 

TRABAJOSDEIA/IA-sesion-2/3trescupos-actividad-ia.md
Documento de la actividad “tres cupos, ocho estudiantes”. Contiene el enunciado, los datos del caso ficticio, el criterio de selección del equipo y las respuestas generadas por distintas IA (ChatGPT en modo pensar, etc.).

TRABAJOSDEIA/IA-sesion-3/paginadeia.md
Recopilación integral de prompts y requerimientos para el diseño de una plataforma web educativa (cursos de programación, foro estilo Reddit, retos tipo Codewars y mentorías). Incluye la definición de la paleta de colores, requisitos funcionales y no funcionales, y prompts para herramientas como Stitch y v0.dev.

🚀 Cómo visualizar el proyecto
Clona el repositorio:

bash
git clone https://github.com/juansebastianortegamesa-ai/trabajosdeia.git
Navega a la carpeta TRABAJOSDEIA y abre los archivos .md en cualquier editor de texto o visor de Markdown.

Para ejecutar el script de Python de la sesión 1, asegúrate de tener Python instalado y ejecuta:

bash
python TRABAJOSDEIA/IA-Sesion-1/tinto.md/ejercicio1.py
Recomendación: Usa un visor de Markdown (como VS Code con la extensión Markdown Preview) para leer los archivos .md con formato.

🎯 Objetivo del Proyecto
Este repositorio refleja el aprendizaje y la aplicación práctica de:

Pensamiento algorítmico: descomposición de procesos cotidianos en pasos secuenciales.

Fundamentos de programación: primeros scripts en Python.

Análisis crítico con IA: evaluación de situaciones y toma de decisiones basada en datos.

Documentación técnica: uso de Markdown para estructurar apuntes, actividades y especificaciones de diseño.
